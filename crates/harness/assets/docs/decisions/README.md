# Decisions

Decision records preserve lasting product, architecture, data ownership,
security, compatibility, and validation choices that future work must inherit.

Use `docs/templates/decision.md`. A decision records the accepted outcome and
constraints separately from the chosen approach, states the assumptions and
evidence behind that approach, and names conditions that should reopen it.
Accepted decisions may be superseded by new authority or material evidence; they
are not the original user goal.

Task-local implementation choices and uncertainties remain in the active
execution plan and do not require a separate decision.

An installed consumer begins with no fabricated decisions. Add local decision
documents here as real choices are accepted, then index them in this file.
